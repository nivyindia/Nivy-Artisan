# Nivy Autonomous Start / Continue Command

**START / CONTINUE this repository.** Read the README (if present), repository purpose, current state, plans, trackers, and existing work. Find the highest-priority incomplete and unclaimed task belonging to this repository. Claim it, mark `IN_PROGRESS`, execute, verify, record evidence/status, commit, release the claim, re-check, and continue automatically. Do not start from scratch or duplicate work. Respect repository-specific governance, provenance, approvals, and protected side effects. Stop only for a genuine blocker requiring human input.

Canonical loop: `CHECK → READ → INSPECT → FIND TASK → CLAIM → IN_PROGRESS → WORK → VERIFY → RECORD → COMMIT → RELEASE → RECHECK → CONTINUE`
